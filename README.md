# Travel App

A modern, responsive travel website built using Next.js and TypeScript, demonstrating component based architecture, clean UI design, and modern frontend development practices.

## Key Features
- Responsive layout optimized for desktop and mobile
- Component driven UI using React
- Smooth scrolling navigation and section-based layout
- Clean project structure using Next.js App Router

## Tech Stack
- React
- Next.js (App Router)
- TypeScript
- Tailwind CSS
